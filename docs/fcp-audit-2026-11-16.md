## Findings
- 31 linked stylesheets and 43 covered stylesheets (including inline/dynamic) on mobile homepage.
- First view typography body/header/menu/intro is Exo; several Roboto and Roboto Slab CSS files are loaded.
- CSS Coverage used ranges are **not** a proof that a stylesheet is unnecessary: CSS may be needed for other pages, viewport sizes, interactions and below-fold content.
- Simulated mobile network/CPU FCP in new browser varies significantly with TTFB, so individual measurements must not be credited as causal improvements without repeated stable A/B.
- Prior browser-only tests show:
  - Deferring jQuery by itself causes `jQuery is not defined` errors.
  - Async loading `sr7.css` raises CLS from ~0.009 to ~0.184, undoing a production CLS fix.
  - Async loading Roboto + Roboto Slab caused network errors and fallback typography in one run, not safe to ship.
  - Deferring Jannah `single.min.css` caused mobile CLS ~0.031 compared to baseline ~0.009.
  - Deferring `widgets.min.css` or dark lightbox skin alone preserved CLS but did **not** demonstrate a repeatable FCP improvement, with measured FCP minus TTFB higher than baseline.
- Target Lighthouse FCP <1.8s, but cannot promise this without changing critical-path design or testing.

## Per-stylesheet removal A/B, browser-only (2026-11-16)

- Script: [scripts/fcp-resource-dequeue-probe.cjs](../scripts/fcp-resource-dequeue-probe.cjs)
- Workflow run: [#43812500654](https://github.com/webnvnesc/ptscps-com-vn/actions/runs/43812500654).
- Each case removed only a linked stylesheet from the live HTML **in a Playwright request interception**. No production modification. The tests also recorded FCP, TTFB, CLS, page errors, computed fonts, Elementor widget types, DOM section geometry and mobile/desktop screenshots.
- Mobile 412px throttled: control FCP 2872ms / 2276ms, with CLS 0.00912 in both. The measured baseline after-TTFB interval was 1484ms / 1450ms.
  - Without Roboto Slab stylesheet: FCP 4252ms, CLS 0.04428; text fell back from Exo to system fonts; **reject**.
  - Without Roboto CSS: FCP 2728ms, CLS 0.00903, after-TTFB 1702ms; slower render delay vs baseline, so no demonstrated improvement.
  - Without both Roboto/Roboto Slab: FCP 3020ms, CLS 0.00903, after-TTFB 1986ms; no demonstrated improvement.
  - Without lightbox CSS: FCP 3548ms, text fell back to system font and section heights changed; **reject**.
  - Without Elementor eicons CSS: FCP 2744ms, CLS 0.00912, after-TTFB 1713ms; no demonstrated improvement; may remove editor/widget icons.
  - Without Jannah fontawesome.css: FCP 2728ms, CLS 0.00912, after-TTFB 1695ms; no demonstrated improvement; may remove icons.
- Desktop 1440px fast CPU: control FCP 1684ms / 2224ms, CLS 0.000475. All candidate removals failed to improve consistently:
  - Without both Roboto styles: FCP 12568ms, console network errors; reject.
  - Without lightbox CSS: 2544ms; no improvement.
  - Without eicons: 3872ms, CLS ~0.000943; no improvement.
- Removing CSS based only on Chrome Coverage is inadequate: site includes image-carousel, posts, widgets and interaction states, while authenticated Elementor Builder depends on editor-only resources.
- **Decision:** No deployed FCP code in this test. The production Jannah child-theme mobile CLS fix is unchanged. Avoid dequeuing typography, slider, or icon CSS without full-page/function regression and repeatable A/B gains.
