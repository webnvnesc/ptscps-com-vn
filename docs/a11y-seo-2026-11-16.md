- Production MU plugin: [deploy/ptscps-a11y-seo.php](../deploy/ptscps-a11y-seo.php), installed via checksum-verified [deploy workflow #43868698526](https://github.com/webnvnesc/ptscps-com-vn/actions/runs/43868698526). A previous first attempt [#43868423666](https://github.com/webnvnesc/ptscps-com-vn/actions/runs/43868423666) failed QA due to a fallback SEO metadata guard; that code was corrected and redeployed successfully.
- Cache purge was **targeted** to exact cached HTML for /, /dich-vu, /lien-he and /c/hoat-dong-cua-cong-ty; did not delete other cache trees. Original older MU plugin responsible for offscreen lazy image loading and Jannah child theme CLS CSS remain unchanged.

## Changes made

1. **SEO:** Add a single descriptive meta description on four audited public URLs even when loaded SEO plugin code provides no description. Scope fallback to audited URLs only to avoid duplicate descriptions on other pages. Content remains authored in WordPress/Elementor.
2. **Image boxes:** Add aria-label to image-only Elementor links based on adjacent visible link title; leave image alt, src, srcset, lazy loading and Jannah/Elementor configuration untouched.
3. **Contrast:** Adjust only two failing home service-card backgrounds (#006ba4 for white text), news post dates (#686868) and services page link titles (#286d92).
4. **Heading/accessibility:** Hide *only* empty top widget h3 headings; add visually hidden H1 to service and contact pages which had none; name linked contact map; merge duplicate “Xem tất cả” and “»” anchors pointing to the same URL into one accessible link while preserving visible copy.
5. **ARIA:** Remove invalid role=listitem from Elementor post article cards and redundant role=list on their grid container, letting articles retain native semantics.
